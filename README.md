# Interactive Book Reader

یک وب‌اپ ساده و سبک (بدون سرور و بدون نصب) برای خواندن کتاب‌ها با بخش‌بندی، ساده‌سازی متن، یادداشت و پیگیری پیشرفت. همه‌ی داده‌ها فایل‌های JSON هستند و کل پروژه با HTML/CSS/JS خالص کار می‌کند.

## نسخه‌ی آنلاین

سایت روی GitHub Pages منتشر شده است:

**https://fakhariyanamirreza-design.github.io/interactive-book-reader/**

## کتاب‌ها

| کتاب | نویسنده | فصل / بخش / سکشن | وضعیت |
|------|---------|------------------|--------|
| **نظریه بازاریابی** (*Marketing Theory: A Student Text*) | بیکر و سارن | ۲۱ / ۱۰۵ / ۶۲۹ | کامل |
| **گاو بنفش** (*Purple Cow*) | ست گودین | ۸ / ۱۶ / ۷۰ | کامل |
| **تبلیغات علمی** (*Scientific Advertising*) | کلود سی. هاپکینز | ۲۱ / ۴۵ / ۱۸۹ | کامل |

- هر سکشن چند پاراگراف فارسیِ ساده‌سازی‌شده دارد
- حدود یک‌سوم سکشن‌ها پرسشِ بازتابی با کلید پاسخ دارند و حدود یک‌سوم مثالِ ملموس
- پیشرفت خواندن، یادداشت و محل آخرین مطالعه در مرورگر (localStorage) ذخیره می‌شود

## اجرای محلی

از داخل پوشه‌ی پروژه یکی از این دستورها را اجرا کن:

```bash
python -m http.server 8000
```

یا:

```bash
npx serve .
```

سپس در مرورگر: `http://localhost:8000`

> چون داده‌ها با `fetch` بارگذاری می‌شوند، باز کردن مستقیم فایل `index.html` (file://) کار نمی‌کند؛ یک وب‌سرور ساده لازم است.

## ساختار پروژه

```
index.html                 نمای اصلی (SPA)
styles.css                 استایل
app.js                     منطق برنامه و مسیرها
data/
  books/
    manifest.json          فهرست کتاب‌ها
    marketing-theory/      نظریه بازاریابی
    purple-cow/            گاو بنفش
    scientific-advertising/  تبلیغات علمی
    <book-id>/
      book.json            مشخصات کتاب
      chapters.json        فهرست فصل‌ها + تعداد سکشن هر فصل
      chapterIndex.json    ساختار فصل‌ها (بخش‌ها و عنوان سکشن‌ها) — برای لود سریعِ صفحه‌ی کتاب
      chapters/
        ch1.json           تعریف فصل (بخش‌ها و مسیر فایل آن‌ها)
        ch1/part1.json     محتوای یک بخش (سکشن‌ها: متن، مثال، پرسش)
        ...
```

## افزودن کتاب جدید

۱. یک پوشه با شناسه‌ی کتاب بساز، مثل `data/books/mybook/`
۲. سه فایل بساز: `book.json` (مشخصات)، `chapters.json` (فهرست فصل‌ها) و `chapters/ch1.json` + فایل‌های بخش
۳. شناسه‌ی کتاب را به `manifest.json` اضافه کن
۴. بعد از نوشتن فایل‌های بخش، `chapterIndex.json` را بازتولید کن (فیلد `sections` در `chapters.json` هم باید با تعداد واقعی سکشن‌ها هماهنگ باشد)

فصل‌های «آماده» (`status: ready`) در داشبورد کتاب باز می‌شوند؛ بقیه با برچسب «به‌زودی» نمایش داده می‌شوند. در کتاب‌های کوتاه/گفتارمحور (مثل گاو بنفش و تبلیغات علمی) هر فصل می‌تواند ۱-۳ بخش و هر بخش ۳-۶ سکشن داشته باشد؛ کلید سکشن همچنان `pX_sY` است.

## پشنهاد برای به‌روزرسانی

تغییر فایل‌های `styles.css` یا `app.js` را با بالابردن شماره‌ی نسخه در `index.html` همراه کن (مثل `app.js?v=6`) تا مرورگر کش قدیمی را نمایش ندهد.

## مثالِ ساختار یک بخش (JSON)

```jsonc
{
  "id": "ch1",
  "title_fa": "بازاریابی: فلسفه یا کارکرد؟",
  "parts": [
    { "id": "p1", "title": "مقدمه و جوهر بازاریابی", "file": "ch1/part1.json" }
  ]
}
```

```jsonc
{
  "id": "p1",
  "title": "مقدمه و جوهر بازاریابی",
  "sections": [
    {
      "id": "s1",
      "title": "بازاریابی: فلسفه یا کارکرد؟ — پرسش اصلی فصل",
      "content": ["پاراگراف اول", "پاراگراف دوم"],
      "example": "یک مثال ملموس",
      "question": { "text": "پرسش بازتابی", "hint": "کلید پاسخ" }
    }
  ]
}
```

محتوای این‌جا ساده‌سازیِ خلاصه‌گونه است و جایگزینِ کتابِ اصلی نیست.
